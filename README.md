# Viral Video Mini App v2 — সবার জন্য এক ডাটা (Shared Database)

ডিজাইন আগের মতোই আছে। নতুন যা যোগ হয়েছে:

- **অ্যাডমিনে যা বদলাবেন, সবার অ্যাপে তা-ই দেখাবে** (ডাটা এখন Upstash Redis ডাটাবেসে, ব্রাউজারে নয়)
- **ছোট শেয়ার লিংক:** `https://t.me/আপনার_বট/app?startapp=5Gz9HwoLRH`
- **বড় শেয়ার বাটন:** চাপলে সরাসরি টেলিগ্রামের কন্টাক্ট/চ্যাট সিলেক্ট স্ক্রিন খোলে
- **লিংকে ক্লিক করলে** সরাসরি ওই পোস্টের এড-লক পেজ খোলে
- **রিয়েল ভিউ কাউন্ট** পোস্টের ছবির উপরে, মোডালে ও ভিউ লাইনে
- **অ্যাডমিন:** ইউজারনেম `admin` — পাসওয়ার্ড শুধু সার্ভারে যাচাই হয়, অ্যাপের কোডে/সেটিংসে নেই, পরিবর্তনের কোনো অপশন নেই
- **১০০–২০০+ জন একসাথে:** ডাটা CDN-এ ক্যাশ হয়, কাউন্টার atomic — কোনো লোড/এরর সমস্যা নেই

## ফাইল তালিকা
```
index.html
index-vv1.js
index-vv1.css
vercel.json
package.json
api/index.js      ← এটা api নামের ফোল্ডারে থাকতে হবে
```

## ধাপ ১ — নতুন GitHub Repository
1. নতুন repo খুলুন (সম্ভব হলে **Private** রাখুন)।
2. `index.html`, `index-vv1.js`, `index-vv1.css`, `vercel.json`, `package.json` — **Add file → Upload files** দিয়ে আপলোড করুন।
3. `api/index.js` ফোনে আপলোড করা কঠিন, তাই: **Add file → Create new file** → নামের ঘরে লিখুন `api/index.js` (স্ল্যাশ দিলেই ফোল্ডার হয়ে যাবে) → ZIP-এর `api/index.js` ফাইলের পুরো লেখা কপি করে বসান → Commit।

## ধাপ ২ — Vercel
1. Vercel → Add New → Project → repo সিলেক্ট। Framework: **Other**, Build Command: ফাঁকা, Output Directory: ফাঁকা।
2. Deploy করুন।

## ধাপ ৩ — ডাটাবেস (একবারই, ফ্রি)
1. Vercel প্রজেক্ট → **Storage** → **Create Database** → **Upstash (Redis)** → Free প্ল্যান → প্রজেক্টে Connect।
2. এতে `KV_REST_API_URL` ও `KV_REST_API_TOKEN` নিজে থেকে বসে যাবে।
3. **Deployments → Redeploy** করুন।

## ধাপ ৪ — টেলিগ্রাম বট (BotFather)
1. `/newapp` → আপনার বট সিলেক্ট → Title/Description/ছবি দিন → Web App URL = আপনার Vercel লিংক → **Short name = `app`**।
2. এখন লিংক হবে: `https://t.me/বটের_ইউজারনেম/app?startapp=কোড`
   (ইউজারনেমের মাঝে স্পেস থাকে না — যেমন `Youtube_bot`)

## ধাপ ৫ — অ্যাডমিন সেটিংস
অ্যাপে ⚙️ → ইউজারনেম `admin` + আপনার পাসওয়ার্ড → **সেটিংস ও এড রোটেশন** ট্যাবে
"বটের ইউজারনেম" (`Youtube_bot`) আর "মিনি অ্যাপ শর্ট নেম" (`app`) দিয়ে সেভ করুন।
এরপর প্রতিটি পোস্টের শেয়ার লিংক ঠিক সেই বটের নামে তৈরি হবে।

## জেনে রাখুন
- অ্যাডমিন পরিবর্তন সবার ফোনে সাধারণত **১–৩ মিনিটের মধ্যে** পৌঁছে যায় (ইচ্ছা করেই ক্যাশ রাখা হয়েছে, যাতে অনেক ইউজারেও অ্যাপ স্মুথ থাকে)।
- থামনেল/ছবি: `https://i.ibb.co.com/.../photo.jpg` বা `.png` সরাসরি লিংক দিন।
- পাসওয়ার্ড ভুল ১০ বার দিলে ১০ মিনিটের জন্য লগইন বন্ধ থাকে (ব্রুট-ফোর্স সুরক্ষা)।
- পাসওয়ার্ড কোডে প্লেইন টেক্সটে নেই, শুধু scrypt হ্যাশ আছে; তবু repo **Private** রাখা ভালো।
- Upstash ফ্রি প্ল্যানের মাসিক কমান্ড লিমিট আছে; ট্রাফিক অনেক বাড়লে সামান্য খরচের পে-এজ-ইউ-গো প্ল্যানে যেতে হতে পারে।
